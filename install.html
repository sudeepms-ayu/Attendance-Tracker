Install in under a minute

Four quick steps. Tap each one as you finish it.

  1. 1

    Download the file

    Tap the gold button above. If your browser asks, choose Keep or Download.

  2. 2

    Open TrackLec.apk

    Tap Open in the download notice, or find the file in your Downloads folder.

  3. 3

    Allow it once

    If Android asks, turn on Allow from this source for your browser, then go back. You only do this one time. Play Protect may ask for a quick check; choose Install anyway if it appears.

  4. 4

    Install and open

    Tap Install, then Open. Add your first class and you're set.
